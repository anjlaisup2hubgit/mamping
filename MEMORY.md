# Rules

Keep this app organized so a beginner can read it.

- Screens go in `pages`.
- Shared pieces go in `components`.
- Saving and loading goes in `data`.
- One job per file.
- No file over 300 lines.
- Before writing anything new, check if it already exists.

# Response

How to respond to the user

- Reply in 1 sentence: no redundancy, nothing obvious.
- Use plain words a beginner knows; if a technical term is needed, explain it in a few words.
- If a better solution than my idea exists, say so in that 1 sentence and wait for my answer before implementing.
