# Project rules

This app is read by beginners. Keep it simple and organized.

1. Screens go in `src/pages/`.
2. Shared pieces go in `src/components/`.
3. Saving and loading goes in `src/data/`.
4. One job per file. Name the file after its job.
5. No file over 300 lines. Split it before it gets there.
6. Before writing anything new, search the project for something that already does it, and reuse it.
7. Use plain words in comments. Start each file with one comment line that says its job.

Server code lives in `api/`. Design pictures live in `design/`.
